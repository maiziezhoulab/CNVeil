# Main Figures Analysis

This directory contains the analysis scripts and step-by-step workflows used to generate the main figures presented in the **CNVeil** manuscript.

Each main figure is organized into an independent subdirectory containing the scripts and documentation required to reproduce the corresponding figure. Input datasets are **not** stored within individual figure directories. Instead, all example datasets are maintained in the repository-wide `example_data/` directory to avoid duplication and simplify data management.

---

## Repository Organization

```text
CNVeil/
├── example_data/                 # Example datasets used throughout the analyses
│
├── Main_figs_analysis/
│   ├── README.md
│   ├── Figure2/
│   ├── Figure3/
│   ├── Figure4/
│   ├── Figure5/
│   ├── Figure6/
│   └── Figure7/
│
└── ...
```

Each figure directory contains:

```text
FigureX/
├── README.md          # Workflow documentation
├── scripts/           # Analysis and plotting scripts 
├── output/            # Generated analysis results or figures
```

Some figures may omit directories that are not required.

---

## Reproducing a Figure

To reproduce a figure:

1. Download or prepare the required input files from the repository's `example_data/` directory.
2. Navigate to the corresponding figure directory.
3. Follow the instructions in the local `README.md`.
4. Execute each script in the documented order.
5. Generated results and figures will be written to the designated output directories.

---


## Notes

* Scripts are documented in the order they should be executed.
* Intermediate files generated by one step serve as inputs to subsequent steps within the same figure workflow.
* All paths shown in the documentation are relative to the repository root unless otherwise specified.
