# CNV benchmark tool scripts

Each tool folder contains its original-style run script, a Slurm submission script, and a short README linking to the original tool. CHISEL and Alleloscope retain their separate preprocessing scripts.

Edit paths in the scripts and use your existing working environments. Reference settings are hg19/GRCh37; supply inputs that actually use that assembly. Evaluation and comparison plots are maintained separately.

Cleanup is limited to path placeholders, formatting, quoting, and small implementation fixes. Original scientific choices are retained; unresolved issues are stated in the individual READMEs. R and biological runs remain unverified.

Included tools: Alleloscope, AneuFinder, CHISEL, CNRein, FLCNA, Ginkgo, HMMcopy, SCOPE, SEACON, SPRINTER, rcCAE, and SeCNV.
